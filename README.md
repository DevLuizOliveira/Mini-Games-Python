# ?? Cassino Python - Jogo de Apostas Simples


Um simulador de máquina caça-níqueis (Slot Machine) desenvolvido em Python que roda diretamente no terminal. 
O projeto explora conceitos de lógica de programação, manipulação de variáveis, estruturas de repetição e funções.


## ?? Funcionalidades


-**Depósito Inicial:** O usuário define quanto deseja colocar na banca.

- **Sistema de Apostas:** Cada rodada custa R$100.

- **Lógica de Premiação:** Sorteio de 3 números aleatórios. Se forem iguais, o jogador ganha R$1000!

- **Gerenciamento de Saldo:** O saldo é atualizado em tempo real e mantido entre novos depósitos.

- **Interface Interativa:** Animações simples com `time.sleep` para simular a rotação da máquina.


## ??? Tecnologias Utilizadas


- **Python 3.12.2**

- **Biblioteca `random`:** Para gerar os resultados aleatórios.

- **Biblioteca `time`:** Para criar o efeito de espera entre os números.
